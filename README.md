## What is BloodBank.software?

BloodBank.software is a free, open source blood bank management system designed for hospitals, NGOs, and government blood banks — particularly across **India** and **Africa**, where purpose-built, affordable blood bank software is critically needed.

Built with modern technology. Licensed for maximum freedom. Designed to save lives.

## Tech Stack

| Layer | Technology |
|---|---|
| Frontend | Next.js |
| Backend | NestJS |
| Database | MongoDB |
| Proxy | Nginx |
| Docs | Swagger |

## Key Features *(coming soon)*

- 🩸 Donor registration & management
- 🗃️ Blood inventory tracking with expiry alerts
- 🔬 Crossmatch & compatibility records
- 📋 Transfusion management
- 📊 Compliance reports (NBTC / NACO ready)
- 🔔 SMS & email notifications
- 👥 Multi-user role-based access
- 🌐 Multi-site support
- 🐳 Docker + one-command installer
